### Week 4 Objectives:

* Learn how to create a relational database with Amazon RDS and connect an application to it.
* Explore Amazon Lightsail deployment options and compute cost optimization.
* Practice application scaling with Amazon EC2 Auto Scaling and a load balancer.
* Learn system monitoring with Amazon CloudWatch metrics, logs, alarms, and dashboards.

### Expected Week 4 Outcomes:

* **Amazon RDS:** Understand database creation, application connectivity, and backup and restore procedures.
* **Amazon Lightsail:** Understand small application deployment, networking, snapshots, and cost considerations when choosing or upgrading a plan.
* **Amazon EC2 Auto Scaling:** Understand launch templates, capacity settings, load balancer integration, and scaling behavior as workloads change.
* **Amazon CloudWatch:** Know how to view metrics, query logs, and use alarms and dashboards to monitor resources.
* **Practice notes:** Record configuration steps, test observations, issues, and cleanup steps for later review.
